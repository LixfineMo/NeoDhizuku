# NeoDhizuku

[Dhizuku](https://github.com/iamr0s/Dhizuku)를 기반으로 한 2차 개발 버전입니다. 기기 소유자(DeviceOwner) 권한을 통제된 방식으로 다른 앱에 공유합니다.

[简体中文](../README.md) | [English](README.en.md) | [日本語](README.ja.md) | [繁體中文](README.zh-rTW.md) | [Deutsch](README.de.md)

---

## ⚠️ 미완성 경고

**현재 개발 중인 버전입니다. 일상 기기나 운영 환경에서 사용하지 마세요.**

패키지 이름이 `com.neodhizuku.more`로 변경되었습니다. 공식 버전과 **함께 설치할 수 없으며**, 공식 ContentProvider authority도 등록하므로 **반드시 공식 Dhizuku를 먼저 제거해야 합니다**. 데이터는 호환되지 않으므로 이전 전에 백업하세요.

## 기능

### 활성화

- **계정 삭제 없이 활성화**: 상위 버전의 "먼저 모든 계정 삭제" 요구 사항이 필요 없습니다(Shizuku / root + Android 13 이상 필요)
- **기기 관리자 모드**: 시스템 설정에서 부여할 수 있어 진입 장벽이 가장 낮지만, 서드파티 클라이언트는 초기화할 수 없습니다(알려진 제한 참조)
- **활성화 오류 안내**: 영어 원본 오류를 원인과 해결 방법으로 바꾸고 진단 정보를 한 번에 복사

### 보안

- **인증 진입점이 클라이언트가 알린 UID를 신뢰하지 않습니다**: 서버가 `Binder.getCallingUid()`로 실제 신원을 확인하고 일회용 토큰(10분 유효)을 발급합니다
- **기기 소유자 이전 차단**: 기본적으로 꺼져 있으며, 거부 시 알림을 보냅니다
- **초기화 강제 확인**: `wipeData`는 항상 차단되며 두 단계 경고와 책임 동의 체크가 필요합니다. 허가는 일회성이며 5분간 유효합니다
- Provider 인증, `remoteProcess` 명령 감사, 시작 시 자체 서명 검증

### 인터페이스

KernelSU 관리자 레이아웃을 참고해 Material3로 구현했습니다(**miuix / coui 미사용**):

- **플로팅 하단 바**: 네 페이지가 공유하며 아이콘 + 텍스트, 이모지 없음. 좌우 스와이프로도 전환 가능. 하위 페이지에서는 표시되지 않음
- **홈 상태 카드**: 활성화 시 "왼쪽 상태 카드 + 오른쪽 작은 카드 2개" — 활성화 상태 + 신분 유형 + 버전, 오른쪽 위 인증된 앱 수, 오른쪽 아래 서비스 가동 시간
- **앱 관리**: 관련 앱을 한 목록에 모으고 스위치가 인증 상태를 직접 표시. 권한을 선언하지 않고 호출한 앱도 자동 등록됩니다
- **블랙리스트 전용 페이지**: 항목별로 해제 가능
- **인증 대화상자**: 진행 표시줄 없음. "허용"은 연한 녹색, "거부"는 빨간색 강조, "블랙리스트"는 검정. 카운트다운은 버튼 줄 아래에 작게 표시
- **호출 기록**: 각 앱이 사용한 기능을 **인자와 함께 알기 쉬운 문장으로** 기록. 30일간 보존되며 각 항목에 서버 로그 조각이 첨부됩니다. "실행 로그" 탭도 포함
- **서비스 시작 / 중지**: 중지 시 가동 시간 카드가 전체 빨간색의 "서비스 거부"로 표시되며, 인증과 호출 기록 조회는 가능
- **테마 페이지**: 다크 모드 4단계(시스템 따름 / 라이트 / 다크 / AMOLED 순수 검정) + 동적 색상. 동적 색상을 끄면 내장 팔레트를 고를 수 있고, 리퀴드 글라스 하단 바 스위치도 제공
- **정보 페이지**: 움직이는 아이콘, 버전과 기기 정보, GitHub / QQ 링크, 업데이트 확인(프리릴리스 수신 토글 포함)

### 서비스(설정 → 서비스)

| 섹션 | 내용 |
|---|---|
| API 서비스 | 마스터 스위치, 화이트리스트 모드, 이전 호환 버전 사용(기본 켜짐) |
| 서비스 중지 시 처리 | 5가지 선택 드로어. 서비스가 중지된 뒤에만 적용 |
| 기기 소유자 이전 | 위 이전 차단의 스위치 |

"이전 호환 버전 사용"은 클라이언트에 반환되는 버전 이름을 결정합니다. 켜짐(기본)이면 상위 버전의 `2.12.0`을 반환합니다(버전을 검사하는 클라이언트가 있기 때문). 끄면 이 프로젝트 자체의 버전 이름을 반환합니다.

서비스 중지 시 처리:

| 선택 | 동작 |
|---|---|
| 위험한 서비스 거부 후 실패 반환 | 서비스는 검색 가능, 읽기 전용이 아닌 작업은 모두 거부 |
| 위험한 서비스 거부 후 성공 반환 | 통과시키지만 실행하지 않고 성공만 반환 |
| 서비스 완전 거부 후 실패 반환 | null 반환, 다른 앱이 서비스를 찾을 수 없음 |
| 서비스 완전 거부 후 성공 반환 | 빈 결과 반환 |
| 아무 처리 없음 | 요청을 보류하고 클라이언트는 무한정 대기 |

"아무 처리 없음"은 스레드를 막는 것이 아니라 **콜백하지 않는** 방식이므로 다른 호출 처리에 영향을 주지 않습니다.

## 사용법

### 활성화

Shizuku, ADB, 계정 삭제 불필요 모드를 지원합니다. 기기 소유자가 되면 서드파티 앱이 Dhizuku API를 통해 기기 소유자 권한을 요청할 수 있습니다.

### 계정 삭제 없이 활성화

상위 버전은 **기기에 계정이 없을 때** 설정할 것을 권장하지만, 이 포크는 ADB 경로 대신 앱 자체 uid로 직접 호출하므로 이 제한을 우회합니다. 시스템은 `hasUserSetupCompleted`만 검사하고 계정을 전혀 읽지 않습니다.

**전제 조건**: Shizuku 또는 root 권한, Android 13(API 33) 이상, 아직 기기 소유자가 아닌 상태.

**부작용**: 0으로 설정된 동안 3버튼 내비게이션의 홈 및 최근 작업 키가 작동하지 않습니다(뒤로 키는 사용 가능, 제스처 내비게이션은 영향 없음). 코드는 `finally`에서 반드시 복구합니다.

### 인증 관리

- 서드파티 앱의 첫 호출 시 인증 요청이 표시되며 허용, 거부, 블랙리스트 중에서 선택합니다
- **블랙리스트에 추가하면 해당 앱의 인증 요청은 더 이상 처리되지 않습니다**
- "앱 관리"에서 언제든 인증을 켜고 끌 수 있고, "블랙리스트" 페이지에서 해제할 수 있습니다
- **화이트리스트 모드**를 켜면 화이트리스트 안의 앱만 위험한 인터페이스를 호출할 수 있습니다

## 알려진 제한

- 리퀴드 글라스는 반투명 오버레이이며 실시간 배경 블러가 아님(Compose에 네이티브 배경 블러 API 없음)
- **기기 관리자 모드에서는 서드파티 앱이 초기화할 수 없습니다**: 클라이언트의 `Dhizuku.init()`는 기기 소유자와 프로필 소유자만 받아들이며 기기 관리자는 즉시 실패합니다. 이 코드는 서드파티 프로세스에서 동작하므로 본 앱에서 영향을 줄 수 없습니다
- 계정 삭제 없는 활성화는 Android 13 이상만 지원
- USB 디버깅이 켜져 있으면 시스템 설정 화면이 열리지 않을 수 있습니다. adb를 끄면 복구됩니다
- Shizuku API 14에서 `newProcess`가 제거되므로, 그 전에 User Service로 이전해야 합니다

## 빌드

Android Studio **Quail 4(2026.1.4)** 이상(AGP 9.4.1 최소 요구 사항), JDK 21. SDK Platform 37, Build Tools 37.0.0, NDK 29.0.14206865를 설치하세요.

```
./gradlew assembleDebug      디버그 빌드
./gradlew assembleRelease    릴리스 빌드
```

결과물은 `app/build/outputs/apk/debug/`에 있습니다.

패키지 이름은 `com.neodhizuku.more`로 고정되어 있고, 공식 authority `com.rosan.dhizuku.server.provider`도 함께 등록하므로 공식 패키지 이름을 하드코딩한 클라이언트(amarok, 爱玩机工具箱 등)도 본 앱에 연결할 수 있습니다.

저장소에 포함된 서명은 디버그용(`keystore/`)입니다. 배포 전에 자신의 서명 설정으로 교체하세요.
