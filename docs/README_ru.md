## Описание

Инструмент, позволяющий делиться разрешениями владельца устройства (DeviceOwner) с другими приложениями.

- [GitHub Дискуссии](https://github.com/LixfineMo/NeoDhizuku/discussions)

## Поддерживаемые версии

Андроид 8.0 ~ 17
