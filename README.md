# NeoDhizuku

基于 [Dhizuku](https://github.com/iamr0s/Dhizuku) 的二次开发版本，把设备所有者（DeviceOwner）权限受控地共享给其他应用。

## 特性

### 激活

- **免删账号临时激活**：免去上游「必须先移除全部账号」的要求（需 Shizuku / root + Android 13+）
- **设备管理员模式**：系统设置即可授予，门槛最低，但第三方客户端无法初始化（见已知限制）
- **激活错误提示**：英文原始报错映射为中文原因 + 处理建议 + 一键复制诊断信息

### 安全

- **授权入口不再信任客户端自报的 UID**：改由服务端用 `Binder.getCallingUid()` 取真实身份并签发一次性令牌（10 分钟有效）
- **设备所有者转移拦截**：默认关闭，拒绝时发出通知
- **擦除设备强制确认**：`wipeData` 一律拦截，需两级警告 + 勾选责任声明才放行；放行一次性且 5 分钟有效
- Provider 鉴权、`remoteProcess` 命令审计、启动时自身签名校验

### 界面

参考 KernelSU 管理端的布局思路，用 Material3 实现（未引入 miuix / coui）：

- **悬浮底部导航栏**：四页共用，图标 + 文字，不使用 emoji；四页可左右滑动切换，也可点击底栏跳转；子页面不显示
- **首页状态卡**：激活后为「左侧状态卡 + 右侧上下两张小卡」——已激活 + 身份类型 + 版本号，右上授权应用数，右下服务运行时间
- **软件管理**：所有相关应用在同一列表，开关直接显示授权状态；未声明权限但发起过调用的应用会自动登记
- **黑名单独立页**：可逐项解除拉黑
- **授权弹窗**：无进度条；允许浅绿、拒绝红色突出、加入黑名单黑色；倒计时小字在按钮行下方
- **调用记录**：记录各应用调用了哪些能力，**口语化描述并带参数**；持久化保存 30 天，每条附服务端日志片段；另含「运行日志」标签
- **服务启停**：停止后运行时间卡整卡纯红显示「拒绝服务」，仍可查看授权与调用记录
- **主题页**：深色模式四档（跟随系统 / 浅色 / 深色 / AMOLED 纯黑）+ 动态取色；关闭动态取色后可用内置取色板，另含液态玻璃底栏开关
- **关于页**：动态图标、版本与设备信息、GitHub / QQ 入口、更新检测（含灰度更新开关）

### 服务（设置 → 服务）

| 分区 | 内容 |
|---|---|
| API 服务 | 总开关、白名单模式、使用旧的兼容版本号（默认开启） |
| 关闭服务后的处理方式 | 五选一抽屉，仅在服务被关闭后生效 |
| 设备所有者转移 | 上述转移拦截的开关 |

「使用旧的兼容版本号」决定返回给客户端的版本名：开启（默认）时返回上游 `2.12.0`——部分客户端会校验版本；关闭时返回本项目自身的版本名。

关闭服务后的处理方式：

| 选项 | 行为 |
|---|---|
| 拒绝危险服务并返回失败 | 可查询到服务，非只读操作一律拒绝 |
| 拒绝危险服务并返回成功 | 放行但不实际执行，只回成功 |
| 完全拒绝服务并返回失败 | 返回 null，其他应用查不到服务 |
| 完全拒绝服务并返回成功 | 返回空结果 |
| 不做任何处理 | 挂起请求，客户端无限等待 |

「不做任何处理」通过**不回调**实现而非阻塞线程，不影响服务处理其他调用。

## 使用方法

### 激活

支持 Shizuku、ADB、免删账号模式。成为设备所有者后，第三方应用即可通过 Dhizuku API 申请使用设备所有者能力。

### 免删账号临时激活

上游建议在**设备上没有任何账号时**配置，本方案绕开了这条限制：以应用自身 uid 直接调用而非走 ADB 分支，系统只校验 `hasUserSetupCompleted`，完全不读账户。

**前提**：Shizuku 或 root 权限、Android 13（API 33）及以上、尚未成为设备所有者。

**副作用**：置 0 期间三键导航的 Home 与最近任务键失效（返回键可用，手势导航不受影响），代码在 `finally` 中必定恢复。

### 授权管理

- 第三方应用首次调用时弹出授权请求，可允许、拒绝或加入黑名单
- **加入黑名单后不再处理该应用的授权请求**
- 「软件管理」中可随时开关授权；「黑名单」页可解除拉黑
- **白名单模式**开启后，仅白名单内的应用可调用高危接口

## 已知限制

- 液态玻璃底栏是半透明叠加效果，不是实时背景模糊（Compose 无原生背景模糊接口）
- **设备管理员模式下第三方无法初始化**：客户端 `Dhizuku.init()` 只认可设备所有者 / 资料管理员，设备管理员会直接返回失败。该代码跑在第三方进程，本应用无法影响
- 免删账号激活仅支持 Android 13+
- 开启 USB 调试时可能出现系统设置页不可访问，关闭 adb 即恢复
- Shizuku API 14 将移除 `newProcess`，届时免删激活需迁移到 User Service

## 构建

Android Studio **Quail 4（2026.1.4）** 及以上（AGP 9.4.1 的最低要求），JDK 21。需安装 SDK Platform 37、Build Tools 37.0.0、NDK 29.0.14206865。

```
./gradlew assembleDebug      调试版
./gradlew assembleRelease    发布版
```

产物在 `app/build/outputs/apk/debug/`。

包名固定为 `com.neodhizuku.more`，同时注册原版 authority `com.rosan.dhizuku.server.provider`，让硬编码官方包名的客户端（amarok、爱玩机工具箱等）也能连到本应用。

仓库内默认是调试签名（`keystore/`），正式分发前请替换为自己的签名配置。
